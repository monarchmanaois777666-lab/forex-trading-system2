## How to deploy on Streamlit Cloud

1. Create a **public** GitHub repository
2. Upload these files to the **ROOT** of the repo (not inside any folder):
   - app.py
   - requirements.txt
   - .streamlit/config.toml  (upload the folder too)
3. Go to https://share.streamlit.io → Sign in with GitHub
4. Click **New app**
5. Settings:
   - Repository: your-repo-name
   - Branch: main
   - Main file path: **app.py**
6. Click Deploy

You will get a public URL that works on phone browsers.
